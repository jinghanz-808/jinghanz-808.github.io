# Helen Zhang — Personal Website

Personal website for Helen Zhang, Computer Science at the University of Utah.

This is a static site built with plain HTML and CSS. It covers research on real-world navigation, egocentric video, and neural data, plus experience, projects, education, and contact information.

## View locally

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server
```

## GitHub Pages

This repository is named `<username>.github.io`, so GitHub Pages serves it at `https://<username>.github.io/`.

To publish, enable Pages in the repository settings with the `main` branch and the root folder, if it is not already enabled.
